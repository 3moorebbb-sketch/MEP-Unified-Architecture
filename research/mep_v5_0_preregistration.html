The Hypothesis

Catastrophic Forgetting can be prevented by protecting the functional surface geometry of a neural network rather than its internal parameters. By treating the $\mathcal{P}$ operator as an elastic tether on the Jacobian Matrix (measured via Hutchinson's JVP trace estimator), the network is allowed to freely scramble its internal weights to learn Task B, provided the topological shape of Task A's attractor basin remains unwarped. This operationalizes the true definition of a "lossy geometric scar."

1. Experimental Design

  • Benchmark: Split MNIST (Task A: Digits 0-4; Task B: Digits 5-9). This perfectly mirrors previous V3.2, V3.3, and V4.0 tests for rigorous comparison.
  • Network: Standard discrete Multi-Layer Perceptron (MEPTopologicalNetwork).
  • The Operation:
    1. Train on Task A. Freeze a copy of the network to act as the topological anchor ($J_A$).
    2. Extract a small subset of unlabeled anchor coordinates ($X_A$) from Task A's dataset.
    3. Train on Task B. At each step, compute the JVP (Jacobian-Vector Product) for both the current model and the anchor model on $X_A$ using a random perturbation vector $v$.
    4. Apply the Topological Tether: $\mathcal{Loss}_{total} = \mathcal{Loss}_{TaskB} + \lambda \cdot MSE(J_{current} \cdot v, J_A \cdot v)$

2. Baselines & Seeds

  • Naive SGD: Standard sequential training (expected 1-2% retention).
  • EWC (Elastic Weight Consolidation): The industry standard for continual learning (achieved ~4.99% in V3.2).
  • Seeds: 20 independent random initializations to ensure statistical significance.

3. Explicit Failure Conditions (Falsifiability)

Failure Conditions

The Jacobian Tethering hypothesis will be considered FAILED if:

  1. Retention Threshold: The MEP Architecture retains less than 80% relative accuracy on Task A. If protecting the Jacobian fails to preserve the functional memory, the geometric scar theory is falsified.
  2. Baseline Equivalence: The MEP Architecture fails to outperform Elastic Weight Consolidation (EWC) by a statistically significant margin ($p < 0.05$). If true topology performs worse than a standard Fisher Information penalty, the added computational complexity of the JVP engine is unjustified.
